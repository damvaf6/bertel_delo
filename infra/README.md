| Lockbox `delo-<env>-app` | `DATABASE_URL` (с `sslmode=verify-full`), ключи хранилища | секреты только в облаке, контейнер читает их сам |

Контейнер ядра (`delo-stage-core`) выкладывается отдельным workflow `Deploy core (Yandex Cloud)` (`.github/workflows/deploy.yml`):
образ → реестр → Serverless Container в сети контура, секреты — из Lockbox; схема базы обновляется самим контейнером
при старте (база закрыта от интернета). Домен и API Gateway — позже.

## Как запускается

1. Конфигурация — `infra/terraform/` (Terraform, провайдер `yandex-cloud/yandex`).
2. Запуск — GitHub Actions `Infra (Yandex Cloud)` → «Run workflow» → контур и действие:
   - `plan` — показать, что будет создано/изменено (ничего не меняет);
   - `apply` — создать/изменить.
3. Workflow сам создаёт каталог контура и закрытый бакет для состояния Terraform,
   берёт временный ключ доступа и удаляет его в конце запуска.
4. В PR конфигурация проверяется без доступа к облаку (`fmt`, `validate`).

сузить до `editor` на каталоги `delo-*`). Ключ не проходит через чат и не попадает в репозиторий.

Для защиты боевого контура: в GitHub → Settings → Environments создать окружение `delo-prod`
с обязательным подтверждением Дамира — тогда `apply` на prod не начнётся без его кнопки.

## Порядок

1. `stage` → `plan` → проверка вывода → `apply`.
2. Проверка: подключение к базе из облачной сети, запись/чтение/удаление файла, наличие первой
   автоматической копии на следующее утро, восстановление копии во временный кластер (учебное).
3. `prod` → `plan` → «да» Дамира (это платёж по договору с Яндексом — раздел 6 устава) → `apply`.

## Ориентировочная стоимость

Уточняется в калькуляторе Яндекса перед `apply` (цены меняются):
- stage: база `b2.medium` + 20 ГБ SSD + бакеты — ≈ 3–5 тыс. ₽/мес;
- prod: база `s3-c2-m8` + 20 ГБ SSD + бакеты — ≈ 10–15 тыс. ₽/мес;
- хранение копий — в пределах сотен рублей при текущих объёмах.
