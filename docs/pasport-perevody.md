# Паспорт модуля «Дело: Переводы» (этап 2а)

Задача 2.57. Только документ — кода нет; модуль подключается после выхода экспертизы на реальные заявки (устав, этап 2а).
По образцу раздела 1а: **перечень услуг, поля заявки, список ИИ-проверок**. Формат — как у описания модуля
`src/modules/expertise.mjs` (проверка — `src/modules/index.mjs`): переносится в `src/modules/translation.mjs` почти
один к одному. Первый исполнитель — ООО «АИС Переводчик». Ядро не меняется: заявки, подбор, оплата 80/20, подпись,
переписка, уведомления, кабинет организации (бюро переводов) — общие.

## 1. Модуль

| Ключ | Значение |
|---|---|
| `id` | `translation` |
| `name` | Переводы и нотариальное заверение |
| `basis` | `contract` (договор с заказчиком), `court` (определение суда о переводе) |
| Подпись результата | УКЭП переводчика — для письменного перевода; для нотариального — подпись нотариуса на бумаге, скан в кабинете |
| Осмотр, экспресс, аналоги | нет |
| Черновик от ИИ | машинный черновик перевода → переводчик правит и отвечает (как черновик заключения в экспертизе) |

## 2. Общие поля заявки (для всех услуг модуля)

| id | Поле | Тип | Обяз. | Варианты / ограничения |
|---|---|---|---|---|
| `lang_from` | С какого языка | select | да | русский, английский, немецкий, французский, испанский, итальянский, китайский, турецкий, арабский, узбекский, таджикский, казахский, киргизский, азербайджанский, армянский, грузинский, украинский, белорусский, другой |
| `lang_to` | На какой язык | select | да | тот же список; не равен `lang_from` (проверка в описании) |
| `purpose` | Для чего перевод | select | да | суд; нотариус и наследство; миграция, ВНЖ, гражданство; учёба, признание диплома; банк, сделка; работа; личное; другое |
| `pages` | Сколько страниц (примерно) | number | нет | 1–2000 |
| `region` | Где получить готовый перевод | select | да | Москва; Московская область; только электронно |
| `comment` | Что ещё важно знать | longtext | нет | до 2000 |

Документы для перевода прикладываются к заявке (сканы, фото, Word) — как основание в экспертизе.

## 3. Услуги и их поля

### 3.1 `written` — Письменный перевод (`paper`: «Перевод»)
| id | Поле | Тип | Обяз. | Варианты |
|---|---|---|---|---|
| `doc_kind` | Что переводим | select | да | паспорт, удостоверение; свидетельство (рождение, брак, смерть); диплом, аттестат, приложение; справка; договор; судебный документ; медицинский документ; учредительные документы; доверенность; другое |
| `terms` | Особые термины | select | нет | юридические; медицинские; технические; финансовые; нет |
| `names` | Как писать имена латиницей (как в загранпаспорте) | text | нет | до 300 |

### 3.2 `notary` — Перевод с нотариальным заверением (`paper`: «Нотариально заверенный перевод»)
Поля 3.1 и:
| id | Поле | Тип | Обяз. | Варианты |
|---|---|---|---|---|

| `delivery` | Как получить | select | да | забрать в офисе; курьер по Москве; почта |

### 3.3 `apostille` — Апостиль и легализация (`paper`: «Документ с апостилем»)
| id | Поле | Тип | Обяз. | Варианты |
|---|---|---|---|---|
| `country` | Для какой страны | text | да | до 100 |
| `doc_kind` | Какой документ | select | да | ЗАГС; образование; судебный; нотариальный; другой |
| `with_translation` | Нужен ли перевод | select | да | да, до апостиля; да, после; нет |

### 3.4 `oral` — Устный перевод (`paper`: «Акт оказания услуг»)
| id | Поле | Тип | Обяз. | Варианты |
|---|---|---|---|---|
| `kind` | Где и как | select | да | у нотариуса; в суде; на переговорах; по видеосвязи; другое |
| `date` | Когда | date | да | не раньше завтра |
| `hours` | Сколько часов | number | да | 1–12 |

### 3.5 `court_translation` — Перевод для суда по определению (`paper`: «Перевод с подпиской переводчика»)
Поля 3.1 и: `case_number` (номер дела, text, да), `court` (суд, text, да); основание — `court`, файл определения
обязателен (как «определение суда» в экспертизе).

## 4. Правила проверки результата (ИИ-проверка + проверка диспетчера)

Общие для всех письменных услуг; `auto` — что ИИ проверяет сам, остальное — ИИ подсказывает места, решает человек.

| id | Правило | Услуги | auto (предложение) |
|---|---|---|---|
| `completeness` | Переведён весь текст: все страницы, штампы, печати, подписи, рукописные пометки, оборот | written, notary, court_translation | `page_count` — число страниц и абзацев оригинала и перевода |
| `accuracy` | Смысл передан точно: нет пропусков, добавлений, искажений | все письменные | — |
| `names_numbers` | Имена, даты, номера документов, суммы совпадают с оригиналом (цифра в цифру) | все письменные | `numbers_match` — сверка всех чисел и дат |
| `names_latin` | Имена и названия — как в загранпаспорте или по правилам транслитерации, одинаково по всему тексту | все письменные | `names_consistent` |
| `terms` | Термины выбраны верно и одинаково по всему тексту (юридические, медицинские) | все письменные | `glossary` — расхождения с глоссарием заказчика |
| `format` | Оформление: расположение как в оригинале, пометки «[печать]», «[подпись]», «[герб]», нумерация страниц | все письменные | `placeholders` |
| `notary_form` | Удостоверительная надпись переводчика: ФИО, образование, подпись; нотариальная надпись на месте | notary, court_translation | — |
| `court_form` | Подписка переводчика об ответственности по ст. 307 УК РФ, номер дела и суд совпадают с определением | court_translation | `court_order` (как в экспертизе) |
| `apostille_form` | Апостиль на нужном документе, страна совпадает с заявкой, перевод апостиля — если нужен | apostille | — |
| `technical` | Технические ошибки: опечатки, лишние пробелы, следы машинного перевода, чужой шаблон | все письменные | `word_fields`, `template` (как в экспертизе) |

## 5. Подбор исполнителя

- Допуск — на пару языков и услугу (например, `written:en-ru`); у переводчика — список языков из профиля
  (перенос профилей из БЕРТЕЛ CRM — мост CRM → Платформа, уже есть в ядре).
- Нотариальное заверение — только переводчик, чья подпись зарегистрирована у нотариуса-партнёра.
- Срочность: обычный — по объёму (около 10 страниц в день), срочный — с наценкой (решает Дамир).

## 6. Вопросы к Дамиру (до начала этапа 2а)

1. Список языков на старте: весь список выше или только те, на которые есть переводчики «АИС Переводчик».
2. Нотариус-партнёр и порядок передачи бумажных оригиналов (курьер, офис).
3. Цена: за страницу по языковой группе или назначает диспетчер, как в экспертизе.
4. Устный перевод — включать ли на старте.
