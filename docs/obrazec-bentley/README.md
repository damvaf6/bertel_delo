# Показательный отчёт об оценке: Bentley Continental GT

Задача штаба 3fb17197 (16.10.2026): как выглядит отчёт об оценке легкового автомобиля, сделанный в «Дело: Экспертиза».
Машину выбрали сами: **Bentley Continental GT, 2019 года, 4.0 V8, пробег 38 500 км, для продажи**. Все данные
вымышленные: VIN, госномер, заказчик, оценщик, СРО, полис, объявления и цены — только для образца, это не оценка
настоящей машины.

## Готовый отчёт
- [`Отчёт об оценке Bentley.docx`](Отчёт%20об%20оценке%20Bentley.docx) — файл Word, как его скачивает эксперт кнопкой
  «Скачать Word»; [`Отчёт об оценке Bentley.pdf`](Отчёт%20об%20оценке%20Bentley.pdf) — то же для просмотра.
- 21 страница: титул, оглавление, 14 разделов по образцу отчёта о транспорте (раздел `draft` в
  `src/modules/expertise.mjs`, уточнён по двум настоящим отчётам 03.10.2026), таблица аналогов с корректировками и
  источниками, фото осмотра с временем и местом съёмки, скриншоты объявлений с отпечатком файла, номер отчёта внизу
  каждой страницы.
- Итог: сравнительный подход — 18 901 000 руб. (вес 0,7), затратный — 19 542 000 руб. (вес 0,3), **рыночная стоимость —
  19 093 000 руб.**

Страницы: [титул](otchet-str-01.jpg), [выводы и задание](otchet-str-03.jpg), [аналоги](otchet-str-07.jpg),

## Как собрать заново
`npx playwright test tests/ui/bentley.spec.mjs` — весь путь на телефоне 412×915; Word, черновик ИИ и итог ИИ-проверки —
в `test-results/obrazec/`, снимки — в `test-results/obrazec/ekran/`. Текст, который дописывает эксперт, —
`tests/ui/bentley-text.mjs`. PDF и картинки страниц: `soffice --headless --convert-to pdf`, `pdftoppm -r 70 -png`.
