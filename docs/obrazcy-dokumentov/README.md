# Образцы: акт осмотра и заключение — Word и PDF (задача штаба 41c17197)

По одному акту осмотра и одному заключению (отчёту) на каждый вид первого выпуска «Экспертизы». Собраны настоящей цепочкой
платформы: заявка → эксперт → осмотр по ссылке (фото с временем и геометкой) → черновик ИИ → правка эксперта →
«Скачать Word» / «Скачать PDF», «Скачать акт осмотра» / «Акт в PDF». **Все данные вымышлены** (адреса, имена, суммы, VIN);
текст разделов — образец того, что пишет эксперт.

| Вид | Акт осмотра | Заключение |
|---|---|---|
| Оценка недвижимости | `1-nedvizhimost-akt-osmotra.docx` / `.pdf` | `1-nedvizhimost-zaklyuchenie.docx` / `.pdf` (отчёт об оценке, 11 стр.) |
| Оценка транспорта | `2-transport-akt-osmotra.docx` / `.pdf` | `2-transport-zaklyuchenie.docx` / `.pdf` (отчёт об оценке, 11 стр.) |
| Ущерб после ДТП | `3-ushcherb-dtp-akt-osmotra.docx` / `.pdf` | `3-ushcherb-dtp-zaklyuchenie.docx` / `.pdf` (заключение эксперта, 9 стр.) |
| Товароведческая | `4-tovarovedcheskaya-akt-osmotra.docx` / `.pdf` | `4-tovarovedcheskaya-zaklyuchenie.docx` / `.pdf` (заключение эксперта, 8 стр.) |

Что в документе: титул (вид документа, номер, услуга, эксперт, дата, город), оглавление, разделы по виду (для оценки — по
ФСО, для заключения эксперта — по ст. 25 73-ФЗ: вводная часть, вопросы, объект, осмотр, исследование, выводы), таблицы из
заявки, в конце — **место под подпись эксперта и печать («М.П.»)**; приложения — акт осмотра и фото осмотра с подписями
(время, место, кто снимал); внизу каждой страницы — номер документа и страница. Подпись и печать ставит эксперт сам —
платформа от его имени ничего не подписывает.

Сверка PDF с Word (18.11.2026): формат A4, шрифт Liberation Serif (по размерам букв как Times New Roman), каждая строка
Word есть в PDF — 0 расхождений во всех 8 парах; страницы просмотрены глазами. Пересобрать:
`node tests/tools/doc-samples.mjs docs/obrazcy-dokumentov` (нужны PostgreSQL как для `npm test` и LibreOffice).
